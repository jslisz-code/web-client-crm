# Web Client CRM

React CRM starter for website-design clients.

## Run in VS Code

1. Open this folder in VS Code.
2. Open Terminal → New Terminal.
3. Run `npm install`
4. Run `npm run dev`
5. Open the localhost link Vite prints.

This first version saves data in `localStorage`, so it works without setting up a database yet.
